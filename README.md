# CodeSense

### Java Code Quality & Code Smell Analyzer

CodeSense is a developer-focused tool designed to analyze Java source code, identify common code-quality issues and code smells, calculate software metrics, and provide actionable suggestions for improving maintainability.

## 🚀 Project Status

Currently under active development.

## 🎯 Planned Features

* Java source-code analysis
* Code smell detection
* Code complexity analysis
* Maintainability metrics
* Code-quality scoring
* Automated improvement suggestions
* Interactive web dashboard
* Machine-learning-based code smell prediction

## 🛠️ Planned Technology Stack

* Python
* Java
* JavaScript
* HTML/CSS
* FastAPI
* SQLite
* scikit-learn
* Git & GitHub

## 🏗️ Planned Architecture

```text
Java Source Code
       ↓
Code Parser / Analyzer
       ↓
Code Metrics + Smell Detection
       ↓
Quality Evaluation
       ↓
Recommendations
       ↓
Web Dashboard
```

## 📌 Motivation

Poorly structured code can become difficult to understand, maintain, test, and extend. CodeSense aims to provide beginner-friendly feedback that helps developers understand common problems in their Java programs and improve their coding practices.
